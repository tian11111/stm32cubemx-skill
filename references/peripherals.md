# F103 外设配置核对要点

这些是任务检查清单，不是能直接套用的 CubeMX 参数或已验证的自动配置模板。先读取目标 `.ioc`、芯片数据手册和真实接线；例子仅用于解释，不证明硬件行为。

- **TIM PWM：** 核对通道、引脚复用、TIM 时钟、预分频与自动重装载。常见向上计数模式频率为 `f_TIM / ((PSC + 1) * (ARR + 1))`；中心对齐、更新事件及特殊模式需按手册另行计算。确认程序启动正确通道并检查占空比范围。
- **TIM 中断：** 核对 TIM 更新事件、NVIC 启用/优先级和 IRQ 处理函数；CubeMX 初始化不代表业务代码已启动中断，也不能证明实际频率。
- **I2C 与 MPU6050：** 核对所选 I2C、SCL/SDA 引脚及复用、总线速率和器件地址；接线、上拉、电压和 ACK 需另做硬件验证。
- **USART 与 DMA：** 核对 TX/RX、波特率、芯片允许的 DMA 控制器与通道、方向、句柄关联和必要的中断；F1 固定映射需查具体芯片手册，不能照搬其他系列。

例：当前飞控 `.ioc` 曾包含 TIM2 PWM、PB8/PB9 I2C1、PA9/PA10 USART1；这些是该项目历史配置，不应作为新工程默认值。配置经 CubeMX 回读后，用 [验收规格](verification.md) 指定真正需要检查的键和文件。

[F103 飞控历史验收示例](../examples/f103-flightcontroller-check.json)只检查其中部分键、文件和函数；不检查 TIM 中断运行、PWM 频率或 DMA。调整任何工程前必须以目标 `.ioc` 和实际要求为准。
